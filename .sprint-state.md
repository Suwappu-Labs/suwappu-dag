## Properties verified

1. **`gateway_fallback_correctness`** (EXIT GATE) — honest IP request
   wrapped in a valid SCION envelope and signed by the gateway always
   verifies. The fallback preserves SCION's path-authentication on
   the validator side regardless of the IP-side hijack potential.
2. **`tampered_response_payload_rejected`** — any byte flip in the
   response payload breaks signature verification with
   `InvalidSignature`.
3. **`envelope_tamper_rejected`** — flipping any byte in the envelope
   after the gateway signs causes `DigestMismatch`.
4. **`foreign_signer_rejected`** — a response signed by a key other
   than `config.gateway_pubkey` fails with `InvalidSignature`.
