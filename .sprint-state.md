## Properties verified

1. **`da_sla_enforced`** (EXIT GATE) — for any (payload, SLA,
   retrieval response) triple, `verify_sla` accepts iff:
   - `responded_at` ≤ `stored_at + retention_rounds`, AND
   - `responded_at - requested_at` ≤ `max_retrieval_latency_rounds`, AND
   - `Cid::of(payload_returned) == commitment.cid`.
   Each broken term surfaces a precise error variant.
2. **`content_address_binding`** — identical payloads collapse to
   identical CIDs; distinct payloads produce distinct CIDs (under
   SHA3-256 collision-resistance).
3. **`late_response_signals_breach`** — latency strictly above the
   SLA window returns `LatencyExceeded` regardless of payload.
4. **`forged_payload_signals_breach`** — a payload whose CID does
   not match the commitment returns `PayloadMismatch`.
