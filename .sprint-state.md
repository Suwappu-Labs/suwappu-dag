## Properties verified

1. **`equivocation_proof_slashes`** (EXIT GATE) — for any DAG containing
   an Authority equivocation, the detection pipeline emits a proof and
   `slash_authority` forfeits 100% of the equivocator's stake and
   expels them from the registry.
2. **`validator_double_vote_slashes_30_percent`** — for any Validator
   double-voter, the detection pipeline emits a proof and
   `slash_validator_double_vote` reduces stake by exactly 30%.
3. **`honest_inputs_produce_no_proofs`** — an honest DAG (one cert per
   `(round, author)`) and an honest vote set (one candidate per
   validator) produce zero proofs.
4. **`slashing_is_idempotent`** — slashing the same Authority twice
   returns the slash on first call and `None` on subsequent calls;
   repeated Validator slashing produces monotonically non-increasing
   forfeit amounts.
