## Properties verified

1. **`reserve_coverage_predicate`** (EXIT GATE) — for any `(rule,
   reserves, outstanding)` triple in the bounded test space, the
   predicate's `Ok(())` / `Err(PredicateFailed)` verdict matches the
   arithmetic relation specified by the rule:
   - 1:1 par: `reserves ≥ outstanding`
   - NAV strike: `reserves × 10_000 ≥ outstanding × basis_points`
   - Jurisdiction: same shape, `ratio_bps` parameterized
2. **`failed_attestation_pauses_minting`** — a failing attestation is
   rejected at submit; `can_mint` returns `NoFreshAttestation` until a
   passing one arrives.
3. **`fresh_passing_attestation_unpauses`** — within TTL, a passing
   attestation enables `can_mint`.
4. **`stale_attestation_pauses`** — `can_mint` returns
   `NoFreshAttestation` once `now_round > attested_at + ttl_rounds`.
