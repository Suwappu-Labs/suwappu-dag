## Real bug surfaced by proptest

The proptest `total_supply_preserved` flagged a `from == to` (self-
transfer) bug in the initial `InMemorySubstrate::apply_intent`: the
two-write sequence (insert `from = X-amount`, insert `to = X+amount`)
overwrote the source decrement with the destination increment when the
addresses coincided, inflating total supply by `amount`. Fixed by
early-returning `Ok(())` after the balance check when `from == to`.
Example tests had not caught this.

   any block sequence; flagged the self-transfer bug above.

   state matches the prefix-replay state up to (but not including) the
   failing index.
