## Properties verified

1. **`fast_path_equivocation_full_slash`** (LOAD-BEARING) — for any
   fast-path certificate whose main-lane window contains a conflicting
   tx, the detection pipeline emits a proof and every seated signer is
   slashed at 100% bonded stake + expulsion. Total stake lost = `q ×
   floor`.
2. **`honest_consistency_produces_no_proof`** — non-conflicting main
   lane produces zero proofs.
3. **`non_signers_are_unaffected`** — slashing touches only members in
   `cert.signers`; the remaining `n - q` authorities remain seated.
4. **`repeat_slashing_is_idempotent`** — running the pipeline a second
   time on the same proof produces no new slashes (every signer is
   already absent).
