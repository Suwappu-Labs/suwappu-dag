### BRIDGE-1 — end-to-end PQ bridge (cross-repo + testnet deploy)

In-repo (`suwappu-dag`) the **source side is complete**: each validator
computes the BLAKE3 digest over `HEADER_DOMAIN || networkId || oracle ||
blockNumber || stateRoot`, signs it with its ML-DSA-65 key
(`crates/suwappu-consensus/src/bridge_header.rs`), and serves it via the
`suwappu_getHeaderAttestation` RPC. What remains is **outside this repo**:
(1) the destination `SuwappuDagQuorumHeaderOracle` contract + the mint
path live in **`suwappu-revm` / `suwappu-db`**, which are **not in this
session's repo scope** (can't be edited here); (2) an **off-chain relayer**
that collects a >2/3-stake quorum of attestations and calls `submitHeader`;
(3) a **deployed public EVM testnet** to run it end-to-end (AWS/creds).
`bridge_header.rs:17` records the oracle is currently "UNFED." To finish:
add `suwappu-revm` to a session (or work in that repo), wire the oracle
→ registry → mint, stand up the relayer, deploy to a testnet, then update
the README "honest framing" note once the path is live. This is the
prerequisite for INTEROP-1 (IQ-010) and a GTM-1 proof point.

### CONF-1 — confidential-transfer demo (needs Track H Phase 2)

`crates/suwappu-l2-confidential` is **Phase 1 only** (note commitments,
nullifiers, L2 addresses — all SHA3-256, no confidentiality-disclosure
surface). The "auditor-key selective disclosure" a demo needs is **Phase
2**, which the crate's own module doc lists as unbuilt: per-account
ML-KEM-768 viewing-key derivation (`SUWAPPU_L2_VIEWING_KEY_V1`), a hybrid
ML-KEM + AES-256-GCM encryption envelope, and memo encrypt/decrypt — with
an explicit "workspace dep choice pending" for the AEAD library. A demo
cannot be built on a disclosure primitive that doesn't exist. To finish:
run a dedicated Phase-2 sprint (decide the AEAD dep; implement viewing
keys + envelope + memo; invoke `crypto-reviewer` on the surface), then the
auditor-disclosure demo + test is a small follow-on. Phase 3 (STARK-of-
ML-DSA spend auth) is separately out of scope. This is a GTM-1 proof point.
