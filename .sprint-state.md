## Properties verified

1. **`did_stark_round_trip`** (EXIT GATE) — `prove_rotation` then
   `verify_rotation_proof` round-trips the statement; any tampered
   field of the proof's statement breaks verification with
   `InvalidSignature`.
2. **`cross_chain_statement_binding`** — flipping `target_chain` (or
   any other field) changes the canonical digest. A proof for one
   chain pair cannot be replayed against another.
3. **`unauthorized_rotation_rejected`** — `prove_rotation` rejects a
   signing method that lacks `CapabilityInvocation` in the old
   document with `UnauthorizedMethod`.
4. **`wrong_signer_rejected`** — a proof produced with a foreign
   secret key (not bound to the named method id) fails verification.
