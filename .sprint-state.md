## What I learned this session that fresh session should know

1. **No local `cargo test` / `cargo build --workspace`** — user explicitly corrected this. Mac is too slow. Use CodeBuild + GHA test job. Single-binary builds (`cargo build --release -p gsx-node --bin gsx-metrics`) are OK for analysis tools only. See memory `gsx-dag-no-local-cargo-test.md`.

2. **Don't run intermediate campaigns** — user said "the campaigns are taking too long, lets just focus on the the builds and debug then when all are done run a campaign". One final campaign at the end of the sprint, not after every commit.

3. **Bash 3.2 (macOS default) lacks `declare -A`** — campaign script uses parallel indexed arrays instead.

4. **`date +%s%3N` is GNU-only** — BSD date on Mac appends literal "N". Use `python3 -c 'import time; print(int(time.time() * 1000))'`. Already fixed in `compliance-campaign.sh`.

5. **SSM `StandardOutputContent` truncates at 24,576 bytes** — S28.1 added S3-push collection via the existing IAM `s3:PutObject` on `logs/*`. Validator EC2 role already has it; no terraform change needed.

6. **Deterministic RNG seed → hash collisions across runs** — S29.1 made loadgen default seed = runtime nanos when user passes `--seed 0`.
