Single writer

Only suwappudb-bridge::Bridge::submit (and the BlockExecutor invoked from execute_block) write to the BalanceStore. suwappudb-lane stages untrusted intents but cannot reach canonical state — the lane separation invariant (suwappu-db Invariant 1).

Dual-VM projection equality (Invariant 2)

EVM and Move read the same BalanceSlot. balanceOf(addr) and Coin::value(addr) agree at every committed block — suwappu-db's proptest dual_projection_equality_holds enforces it at 10k cases.

Replay equivalence (Invariant 7)

Recovery replay reapplies the committed blocks from the anchor pipeline and produces the same state tree root.

Why the chain inherits these

suwappu-execution is a thin adapter; the substrate invariants travel through unchanged. See architecture/suwappu-db-bridge.md for the full integration boundary writeup.
