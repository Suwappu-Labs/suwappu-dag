Honest path

A round-R cert with ≥ quorum_threshold(n) distinct supporters at R+1 finalizes via the direct rule. quorum_threshold(n) = n − ⌊(n−1)/3⌋ per IQ-001.

Indirect path (IQ-002)

If round R stays Undecided, scan for an anchor at R' ≥ R+2 that's directly decided; walk its causal_history to settle R as Direct or Skip.

Orphan window (IQ-004)

If the leader's R cert is delivered after peers proposed R+1, the cert is not a parent of any R+1 cert. Orphan-pull adds it to the DAG but causal_history walks parents only — the late cert is unreachable from any anchor and the slot is permanently Skip. One-shot intents in that cert vanish from the commit pipeline.

Joint quorum

Not shown — the Validator Ring also co-signs before any candidate finalizes (paper Theorem 2's AND-gate). See architecture/safety-liveness.md.
