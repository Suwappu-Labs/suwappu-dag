LTP lifecycle at a glance

Key facts

  • LTP is the corridor settlement protocol.
  • It uses a commit / lattice / materialize lifecycle.
  • The sender-to-receiver wire cost is constant size.
  • The gsx-db anchor is one input to the downstream attestation pipeline.
