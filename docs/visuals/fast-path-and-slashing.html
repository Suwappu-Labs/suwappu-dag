Why the fast path exists

Single-owner transactions don't need a full DAG round; one Authority's binding signature is enough. The fast path is a 1-RTT happy-path for those — clients see commit-confirmation in milliseconds instead of waiting for the next commit wave.

K-binding cross-check (IQ-003)

Every fast-path cert is reconciled against the main_lane_index populated by try_commit. A mismatch within the K-window — i.e., the main-lane ordering disagrees with the fast-path commit — yields an EquivocationProof that any honest validator can publish.

100% slashing (Invariant 5)

Slashing for fast-path equivocation is total: 100% of bonded stake + immediate Authority Ring expulsion. Non-interactive, publishable proof. Paper §6.4 + DAG-S9 proptest gate at 10k cases.
